Disseminates the valid beacons towards multiple interfaces of the appropriate neighbours until the limit for sending beacons with equal source ASes to one neighbour is reached.

Iterates over all the beacons for all the neighbours of the node. If the beacon is valid, its dissemination towards this neighbour does not create a loop in the path and the neighbour is not the same AS which originated the beacon it is sent over the interfaces towards this neighbour until the maximum number of beacons to send per neighbour has been reached.
